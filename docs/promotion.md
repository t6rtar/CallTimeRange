# Promotion kit

## Short description

Show start and end times on completed Discord call messages.

## Discord post

I made CallTimeRange, a Vencord userplugin that adds the end time to completed Discord call messages. It uses Discord's stored timestamps, updates calls when they end, and has an option to leave calls under one minute unchanged. Screenshot and installation steps: https://github.com/t6rtar/CallTimeRange

## Forum post

**Title:** I made a Vencord plugin that shows when Discord calls ended

CallTimeRange adds the stored end time beside the start time on completed call messages. It updates calls that end while the channel stays open and can leave calls under one minute unchanged.

Screenshot, source, and installation steps:

https://github.com/t6rtar/CallTimeRange
