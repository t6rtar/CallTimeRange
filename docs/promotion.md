# Promotion kit

## Short description

Show start and end times on completed Discord call messages.

## Discord post

I made CallTimeRange, a Vencord userplugin that adds the end time to completed Discord call messages. It uses Discord's stored timestamps, updates calls when they end, and can show exact seconds. Screenshot and installation steps: https://github.com/t6rtar/CallTimeRange

## Forum post

**Title:** I made a Vencord plugin that shows when Discord calls ended

CallTimeRange adds the stored end time beside the start time on completed call messages. It updates calls that end while the channel stays open, hides short calls by default, and can show exact seconds when needed.

Screenshot, source, and installation steps:

https://github.com/t6rtar/CallTimeRange
