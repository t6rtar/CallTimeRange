# Contributing

Bug reports and focused fixes are welcome.

## Bug reports

Search existing issues first. Include your Discord or Vesktop version, Vencord commit, locale, time format, and reproduction steps. Remove usernames, server names, and private messages from screenshots.

## Code changes

- Keep each change focused on one behavior.
- Follow the surrounding TypeScript and CSS style.
- Test completed and active calls.
- Test the short-call setting in both positions.
- Run `pnpm testTsc` and `pnpm build` before submitting the change.
